How to Run on a ModRetro Chromatic

  1. Download the uncompressed 32 KB ROM: modretro-tetris.gbc.
  2. Via Flashcart (EverDrive-GB X7 / EZ-Flash Jr.): Copy modretro-tetris.gbc directly onto your FAT32 microSD card (uncompressed) and boot it on your ModRetro Chromatic.
  3. Via Dedicated GBC Cartridge: Flash modretro-tetris.gbc onto any 32 KB+ reflashable Game Boy Color cart using GBxCart RW or Joey Jr., then insert into your Chromatic.
  4. Via Desktop / Mobile Emulator: Open modretro-tetris.gbc directly in SameBoy, mGBA, BGB, OpenEmu, or Delta.
